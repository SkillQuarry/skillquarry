# SkillQuarry

SkillQuarry is a beginner-friendly programming learning platform focused on helping students move from concept to confident practice through structured learning paths.

## V1 goal

This first frontend foundation establishes the app shell, routing, placeholder pages, global layout, and future-ready TypeScript models for a course-driven learning experience.

## Technology stack

- React
- TypeScript
- Vite
- React Router
- Tailwind CSS

## Local development

```bash
npm install
npm run dev
```

## Production build

```bash
npm run build
```

## Current project status

- Frontend foundation complete for V1
- Placeholder pages and routing configured
- Reusable UI foundation added
- No Supabase, database, auth, or backend logic implemented yet
